# AOI-Net: Structural Face AOI-Guided Eye-Gaze Track Representation Learning for Autism Spectrum Disorder Detection

This repository contains the official PyTorch implementation of our paper:

> **AOI-Net: Structural Face AOI-Guided Eye-Gaze Track Representation Learning for Autism Spectrum Disorder Detection**  
> Zhanpei Huang, Binbin Sun, Jialiang Chen, Yiou Wang, Taochen Chen, Yuzhu Ji, Yiqun Zhang, Yiu-ming Cheung  
> *IEEE Computational Intelligence Magazine*, 2026

AOI-Net leverages **Area-of-Interest (AOI) structural priors** from facial regions and **eye-gaze temporal dynamics** to learn discriminative representations for Autism Spectrum Disorder (ASD) screening. The model integrates a graph-based AOI encoder with a gaze trajectory transformer, achieving state-of-the-art performance on multiple ASD eye-tracking benchmarks.
